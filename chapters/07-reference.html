In Simple Terms · Quick Lookup Cheat Sheet

The entire neural network theory in three golden rules:

  • Golden Rule 1 (Forward Flow): Inputs multiply weights from the right: \(z^l = W^l a^{l-1} + b^l\). Destination neurons are rows; source neurons are columns.
  • Golden Rule 2 (Backward Flow): Errors pull backward through transposed weights: \(\delta^l = ((W^{l+1})\T \delta^{l+1}) \odot \phi'(z^l)\). The transpose flips rows and columns to reverse signal flow.
  • Golden Rule 3 (Parameter Gradients): Biases get raw error (\(\nabla_b C = \delta\)). Weights get an outer product of outgoing error and incoming activation (\(\nabla_W C = \delta (a^{\text{in}})\T\)).
1. Matrix Contraction
Forward Contraction

Inner dimensions collapse: \((n_l \times n_{l-1})(n_{l-1} \times 1) \to n_l \times 1\).

2. Wire Inversion
Transpose Pullback

Transposing flips rows & columns so errors flow backwards: \((W^{l+1})\T \delta^{l+1}\).

3. Outer Product
Matrix Expansion

Column times row expands into a full matrix: \(\delta^l (a^{l-1})\T = \nabla_W C\).

Master Visual Formula Decoder · The Four Backprop Pillars
BP1: \(\delta^L = \nabla_a C \odot \phi'(z^L)\) Output Error Seed

Compares prediction against target, modulated by the output gate's slope.

BP2: \(\delta^l = ((W^{l+1})\T\delta^{l+1}) \odot \phi'(z^l)\) Hidden Layer Pullback

Pulls blame backward through transposed connection weights layer by layer.

BP3: \(\nabla_b C = \delta\) Bias Gradients

Biases inherit the raw node errors directly with zero extra arithmetic.

BP4: \(\nabla_W C = \delta (a^{\text{in}})\T\) Weight Gradients

Outer product multiplying outgoing error by incoming wire activity.

Matrix calculus results

\[ \nabla f=\begin{bmatrix}\partial f/\partial x_1\\ \vdots\\ \partial f/\partial x_n\end{bmatrix} \qquad\qquad \bigl(J_f\bigr)_{ij}=\frac{\partial f_i}{\partial x_j} \]
\[ J_{f\circ g}(\mathbf x)=J_f\bigl(\mathbf g(\mathbf x)\bigr)\,J_g(\mathbf x) \qquad\text{(outer factor on the left)} \]
\[ \frac{\partial(\mathbf v\odot\mathbf w)}{\partial\mathbf v}=\operatorname{diag}(\mathbf w), \qquad \frac{\partial(\mathbf v\odot\mathbf w)}{\partial\mathbf w}=\operatorname{diag}(\mathbf v) \]
\[ \frac{\partial(\mathbf vz)}{\partial z}=\mathbf v, \qquad \frac{\partial(\mathbf v+z)}{\partial z}=\mathbf 1, \qquad \frac{\partial}{\partial\mathbf v}\sum_i v_i=\mathbf 1\T \]
\[ \mathbf 1\T\operatorname{diag}(\mathbf x)=\mathbf x\T, \qquad \operatorname{diag}(\mathbf u)\mathbf v=\mathbf u\odot\mathbf v \]

Network equations

\[ z=\mathbf w\T\mathbf x+b, \qquad a=\phi(z) \qquad\text{(one neuron)} \]
\[ z^l=W^la^{l-1}+b^l, \qquad a^l=\phi(z^l) \qquad\text{(one layer)} \]
\[ a^0=\mathbf x, \qquad \hat y=a^L \qquad\text{(forward pass endpoints)} \]
\[ C=\frac{1}{2m}\sum_{i=1}^{m}\bigl(y^{(i)}-a^{L,(i)}\bigr)^2, \qquad \nabla_aC=a^L-y \]

The four equations of backpropagation

\[ \delta^L=\nabla_aC\;\odot\;\phi'(z^L) \]
\[ \delta^l=\Bigl(\bigl(W^{l+1}\bigr)\T\delta^{l+1}\Bigr)\;\odot\;\phi'(z^l) \]
\[ \nabla_{b^l}C=\delta^l \]
\[ \nabla_{W^l}C=\delta^l\bigl(a^{l-1}\bigr)\T \]

Component-wise, for anyone implementing them with explicit loops:

\[ \delta^L_j=\frac{\partial C}{\partial a^L_j}\phi'(z^L_j), \qquad \delta^l_j=\Bigl(\sum_k w^{l+1}_{kj}\delta^{l+1}_k\Bigr)\phi'(z^l_j) \]
\[ \frac{\partial C}{\partial b^l_j}=\delta^l_j, \qquad \frac{\partial C}{\partial w^l_{jk}}=a^{l-1}_k\,\delta^l_j \]
Index order in the component form of BP2

The sum runs over \(w^{l+1}_{kj}\), not \(w^{l+1}_{jk}\). The first index \(k\) ranges over layer \(l+1\) and the second \(j\) is fixed in layer \(l\) — that swap is the transpose in the vectorised form. It is the easiest index in the whole subject to write backwards, and a transposed sum produces a wrong gradient that still runs without error.

Optimisation

\[ \theta\;\leftarrow\;\theta-\eta\,\nabla_\theta C \]
\[ \frac{\partial C}{\partial w_i}\approx\frac{C(w_i+\varepsilon)-C(w_i-\varepsilon)}{2\varepsilon}, \qquad \varepsilon\approx10^{-5} \qquad\text{(gradient check)} \]

The training loop

  1. Shuffle the training set and cut it into mini-batches.
  2. For each mini-batch:
    1. Forward pass; store every \(z^l\) and \(a^l\).
    2. Evaluate the cost \(C\).
    3. BP1 for \(\delta^L\).
    4. BP2 backwards for \(\delta^{L-1},\dots,\delta^1\).
    5. BP3 and BP4 for all parameter gradients; average over the batch.
    6. Update with O1.
  3. Repeat until the cost stops improving.

Glossary

ActivationA neuron's output after the non-linearity, \(a=\phi(z)\).
BackpropagationComputing \(\nabla_\theta C\) by propagating node errors backwards through the network. Reverse-mode automatic differentiation, specialised to neural networks.
Batch / mini-batchThe set of examples averaged over before one parameter update.
Cost (loss) functionThe scalar measure of wrongness that training minimises.
Dying ReLUA neuron whose pre-activation is negative on all inputs, so every gradient through it is zero and it can never recover.
EpochOne complete pass over the training set.
Forward propagationEvaluating the network from input to prediction.
GradientThe vector of partial derivatives of a scalar function; points toward steepest ascent.
Hadamard productElement-wise multiplication of two equal-length vectors, written \(\odot\).
HyperparameterA value set by the practitioner rather than learned — learning rate, batch size, layer widths.
JacobianThe matrix of first partials of a vector-valued function; rows index outputs, columns index inputs.
Learning rate \(\eta\)Step size along the negative gradient.
Node error \(\delta^l_j\)\(\partial C/\partial z^l_j\): how much the cost responds to this neuron's pre-activation.
Pre-activation \(z\)The weighted sum plus bias, before the activation function.
Scalar expansionBroadcasting a scalar to a vector so an element-wise operation is defined.
UnrollingFlattening all weight matrices and bias vectors into one long vector \(\theta\).
Vanishing gradientError shrinking toward zero as BP2 is applied through many layers, stalling learning in early layers.

The whole guide in four lines

A network is a composition of functions. Its cost is a scalar function of its parameters. Backpropagation computes every partial derivative of that cost in one backward sweep. Gradient descent walks against them until the cost stops falling.
